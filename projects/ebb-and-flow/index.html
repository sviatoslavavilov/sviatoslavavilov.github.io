Projects / Ebb and Flow

Ebb and Flow

Audiovisual Spectacle · 2023–2024
composition · conducting · live visuals · coding

Four-part audiovisual cycle exploring process self-similarity across universal scales. Music for live ensemble with real-time generative visuals produced using Sviatoslav Avilov's Multiplato software (based on a modified Iterated Function System algorithm).

Crystal — nano-micro crystalline formation · Arboretum — growth of trees and human existence · Mountain — petrification and transfiguration · Ab Infinito — cosmos and return to the origin.
