07. Granular DB Selectors, Text Concatenation & Overrides

1. Extract single field with automatic LaTeX cleaning: getText('beast', 'concept')

"People saying one thing while thinking another. Crocodile tears"

2. Concatenate non-empty text parts: concatTexts(' · ', perf.year, perf.place, perf.organic)

2025 · Palazzo Pisani · electric guitar, clarinet and live electronics

3. LaTeX / Macro-style Template: formatTemplate('{title} ({year}) — {organic}', 'beast')

Beast (2025) — electric guitar, clarinet and live electronics

4. Custom Overrides: getPerformance('beast', { role: 'composition · sound design' })

Allows overriding any specific property while automatically pulling all other fields from the database stub.

5. Modular Multi-Key Assembly (like Il Riso dopo il pianto):
getPerformance({
  stub: 'Il Riso Dopo Il Pianto',
  video: 'elogio-agli-ucc',       // sub-key video instead of standard yout
  desc: ['shdesc', 'credits'],    // auto-concatenates main description + credits
  role: 'composition',
})

Selects a specific video sub-key and automatically stitches multiple text fields from the database cleanly.
